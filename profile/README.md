# Tailor Game

[Tailor Game](https://tailorgame.com/) is a browser arcade and AI game creation platform. Play original games solo or invite friends to supported multiplayer games. In [Tailor Game Studio](https://tailorgame.com/studio), describe a game idea, play the first version in your browser, and refine it through chat.

- [Browse the game catalog](https://tailorgame.com/games) for strategy, card, puzzle, racing, and arcade games.
- [Read the game rules](https://tailorgame.com/blog/game-rules) for controls and available modes.
- [Explore the developer documentation](https://tailorgame.com/docs) for the public game catalog API and integration guides.
- [Use the Tailor Game integrations](https://github.com/Tailor-Game/tailorgame-integrations) for the JavaScript and Python SDK source, command-line client, and public integration skill.
- [Contact Tailor Game](https://tailorgame.com/contact) for product or support questions.
